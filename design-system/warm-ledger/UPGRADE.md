# 0.2 页面与交互补充

沿用五种已确认主题、离线中文字体与数字字体。Impeccable 用于信息分层、详情收纳和实际截图检查；UI UX Pro Max 用于 Flutter 表单、触摸和图表指导。其 design-system 查询返回营销落地页，不适用于离线账本，因此未采用该布局与配色；改用已核对的个人财务产品/Flutter建议。

- 保留五个底部目的地，个人统计由头像进入。
- 首页优先个人资产、代管金额、最大执行计划的可花额与趋势。
- 列表每页6项，月年切换；账户分账户/应收/代管，账本按收支/转账/作废过滤。
- 计划详情默认折叠每日规划、预算、分类、预留和历史。
- 分类最多三级，逐级选择，搜索可跨层定位；老分类保留。
- 图表年/月以柱或折线呈现，日视图用日期金额网格；可跳转流水。
- 卡片16dp圆角，仅保留边框；减少嵌套卡片与装饰。
- 图表数据通过可读金额和点击标签提供等价访问。
