# Bundled fonts

- LedgerSans-400/600.ttf: static subsets of Google Fonts Noto Sans SC.
- Manrope-600.ttf: static subset of Google Fonts Manrope for amounts.
- Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
- Source: https://github.com/google/fonts/tree/main/ofl/manrope

Both are under the SIL Open Font License; the full licenses are included.
The modified subsets have distinct internal family names. Chinese coverage includes
GB2312 plus application text and common symbols. Uncovered characters use the
device's system fallback. All fonts load from APK assets with no runtime network.
